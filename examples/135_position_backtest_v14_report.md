- **建仓**: 10份阶梯建仓

- **止损**: 7%移动止损（从买入后最高价回撤7%触发）
- **卖出**: 均线信号触发（MA13死叉/空头排列/一阴破三线）

4. 放量突破MA55 (中)

### 1.3 卖出信号
1. MA13死叉MA55
2. 空头排列下跌

## 七、策略评价

### 7.1 优势
- **止损有效**: 最大亏损-9.97%，未超过10%
- **趋势捕捉**: 满仓后能抓住较大行情(+40.29%)
- **信号频率**: 150只股票均有交易，信号覆盖率100%

### 7.2 不足
- **胜率偏低**: 42%胜率，低于50%
- **平均收益低**: +1.30%平均收益
- **交易次数少**: 平均1次/只，未能多次交易

### 7.3 改进方向
1. **增加持仓周期**: 当前平均15.7天，可延长至30-60天
2. **优化信号过滤**: 增加成交量/波动率过滤
3. **多股票组合**: 同时持有10-20只，分散风险
4. **动态仓位**: 根据信号强度调整仓位大小
