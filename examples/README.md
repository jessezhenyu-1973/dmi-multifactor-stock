# 运行范例输出（examples）

本目录收录各脚本**真实跑出的结果**，供调用方对照预期输出格式与数量级。
所有数据均来自 2023–2024 沪深300 成分股（hfq 后复权 + 真实基本面 + 交易成本模型），
仅作方法演示，**不构成任何投资建议**。

| 文件 | 对应脚本 | 说明 |
|------|----------|------|
| `final_backtest.log` | `run_tuned.py` | 最终对比报告：原 10 股基线 vs 沪深300 调参后的收益/夏普/回撤/胜率。 |
| `robustness.log` | `robustness.py` | 样本外（过拟合）检验：6 权重预设 × (2023/2024/全2年) 稳定性矩阵 + 推荐生产默认。 |
| `robustness_result.json` | `robustness.py` | 上述检验的结构化结果（便于程序解析）。 |
| `tune_best.json` | `tune.py` | 网格搜索选出的优选配置（预设名 / Top-N / 调仓频率 / 权重向量）。 |
| `real_backtest_fundamental.log` | `multi_factor_dmi_strategy.py --real` | 单轮真实回测样例：接入真实基本面后的逐指标结果。 |

## 关键结论速览（来自上述范例）
- **单年（2024）网格冠军 `sent_low` 在 2 年全样本反亏**（-6.86% / 夏普 -0.45）→ 单年搜索严重过拟合，**严禁把单年冠军当生产默认**。
- **2 年全样本最稳预设 = `base`**（收益 +26.09% / 夏普 0.55）与 `even`（夏普 0.54）。
- **推荐生产默认权重 = `base`**：`(0.12, 0.12, 0.08, 0.08, 0.08, 0.10, 0.10, 0.18, 0.14)`，Top-N=5，调仓 20 日。
- 扩池后（沪深300 vs 原10股，2024）：收益 18.27% → 43.33%，夏普 0.82 → 1.49，回撤 -11.67% → -17.48%。

> 注：以上为历史回测，因子权重/Top-N 对区间高度敏感；正式上线前务必用 `robustness.py` 做样本外检验。
