## 🚀 V9 多源融合策略（当前版本）

V9 策略在 v8 基础上进行了全面优化，引入了多时间框架确认、风险平价分配和同花顺财务数据增强。

### 核心优化点

#### 1. 多时间框架动量因子
- **v8**: 仅使用 20日/60日动量
- **v9**: 扩展至 5日/20日/60日/120日
- **新增**: 多时间框架一致性确认（同时为正时加分）
- **作用**: 更好捕捉短期波动与长期趋势的共振

#### 2. 增强均线系统
- **v8**: 5日/20日均线
- **v9**: 5/10/20/60/120日均线全面覆盖
- **新增**: 均线多头排列确认（MA5>MA20>MA60）
- **作用**: 更严格的趋势过滤，减少假突破信号

#### 3. 风险平价权重分配
- **v8**: 等权分配资金
- **v9**: 波动率倒数加权（低波动股票分配更多资金）
- **公式**: `权重_i = (1/σ_i) / Σ(1/σ_j)`
- **作用**: 降低组合整体波动，提升夏普比率

#### 4. 财务因子增强（同花顺 MCP）
- **v8**: 无基本面数据
- **v9**: 接入同花顺 MCP 财务数据
  - ROE > 15%：质量确认
  - PE 在 0-50 范围：估值合理
  - 营收增速 > 0：成长正向
- **作用**: 基本面过滤，选择优质标的

#### 5. 信号阈值优化
- **v8**: 信号阈值 ≥2
- **v9**: 信号阈值 ≥3（更严格）
- **作用**: 减少假信号，提升胜率

#### 6. 技术指标增强
- **RSI**: 增加超买/超卖双确认
- **成交量**: 5日+20日双确认
- **价格位置**: 20/60/120日分位数

## 🚀 V10 智能优化策略（当前版本）

V10 在 V9 基础上引入了**因子权重网格搜索**和**市场状态切换**两大核心优化，实现了收益和风险指标的进一步提升。

### 🔍 因子权重网格搜索

**原理**: 对 6 个因子类别（DMI/动量/均线/RSI/成交量/价格位置）的权重进行组合搜索，自动找到最优配置。

**搜索空间**:
- DMI: 2.0, 2.5
- 动量: 1.0, 1.5
- 均线: 1.0, 1.5
- RSI: 1.0
- 成交量: 1.0
- 价格位置: 1.0

**Top 5 最优组合**:
```
排名   夏普     收益       回撤    DMI   动量   均线   RSI   量
  1    1.89   34.12%   -9.66%    2.0    1.0    1.5   1.0   1.0
  2    1.82   30.79%   -9.69%    2.5    1.5    1.0   1.0   1.0
  3    1.75   30.10%   -9.69%    2.5    1.5    1.5   1.0   1.0
  4    1.72   30.05%   -9.49%    2.0    1.5    1.5   1.0   1.0
  5    1.64   28.19%  -13.66%    2.5    1.0    1.5   1.0   1.0
```

**结论**: 
- 最优权重组合: **DMI=2.0, 均线=1.5**（DMI 和均线权重最高）
- 动量因子权重在 1.0~1.5 之间表现均衡
- RSI/成交量/价格位置权重 1.0 即可

## 🔧 快速开始

### 1. 安装依赖

```bash
# 创建虚拟环境
python -m venv venv
source venv/bin/activate

# 安装依赖
pip install pandas numpy pytdx akshare fastmcp
```

### 2. 配置 MCP 数据源

```yaml
# config.yaml
mcp_servers:
  tdxquant:
    command: python
    args: [server.py, sse]
    sse_url: http://0.0.0.0:8080/sse
  
  fuyao-a-share:
    sse_url: fuyao.aicubes.cn/mcp/a-share
    headers:
      Authorization: "Bearer $HITHINK_FINANCE_API_KEY"
  
  akshare-one-mcp:
    command: uvx
    args: [akshare-one-mcp]
```

## 📋 策略逻辑

### V9 信号评分系统

```python
score = 0

# 1. DMI 信号 (核心，权重最高)
if +DI > -DI: score += 2
if ADX > 25: score += 1
if ADX 上升: score += 1

# 2. 多时间框架动量
if momentum_20 > 0: score += 1
if momentum_60 > 0: score += 1
if 多框架一致: score += 2

# 3. 均线系统
if 价格 > MA5: score += 1
if 价格 > MA20: score += 1
if 价格 > MA60: score += 1
if 多头排列: score += 2

# 4. RSI
if RSI < 30 (超卖): score += 1
if RSI < 70 (未超买): score += 1

# 5. 成交量
if 放量: score += 1
if 持续放量: score += 1

# 6. 财务因子 (同花顺)
if ROE > 15%: score += 1
if PE 合理: score += 1
if 营收增长: score += 1

# 买入条件: score >= 3
```

### 资金分配（风险平价）

```python
# 波动率倒数加权
volatility = 20日收益率标准差
weight_i = (1/vol_i) / Σ(1/vol_j)
position_size = capital * weight_i
```
