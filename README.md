## 🚀 V9 多源融合策略（当前版本）

V9 策略在 v8 基础上进行了全面优化，引入了多时间框架确认、风险平价分配和同花顺财务数据增强。

### 核心优化点

#### 1. 多时间框架动量因子
- **v8**: 仅使用 20日/60日动量
- **v9**: 扩展至 5日/20日/60日/120日
- **新增**: 多时间框架一致性确认（同时为正时加分）
- **作用**: 更好捕捉短期波动与长期趋势的共振

#### 2. 增强均线系统
- **v8**: 5日/20日均线
- **v9**: 5/10/20/60/120日均线全面覆盖
- **新增**: 均线多头排列确认（MA5>MA20>MA60）
- **作用**: 更严格的趋势过滤，减少假突破信号

#### 3. 风险平价权重分配
- **v8**: 等权分配资金
- **v9**: 波动率倒数加权（低波动股票分配更多资金）
- **公式**: `权重_i = (1/σ_i) / Σ(1/σ_j)`
- **作用**: 降低组合整体波动，提升夏普比率

#### 4. 财务因子增强（同花顺 MCP）
- **v8**: 无基本面数据
- **v9**: 接入同花顺 MCP 财务数据
  - ROE > 15%：质量确认
  - PE 在 0-50 范围：估值合理
  - 营收增速 > 0：成长正向
- **作用**: 基本面过滤，选择优质标的

#### 5. 信号阈值优化
- **v8**: 信号阈值 ≥2
- **v9**: 信号阈值 ≥3（更严格）
- **作用**: 减少假信号，提升胜率

#### 6. 技术指标增强
- **RSI**: 增加超买/超卖双确认
- **成交量**: 5日+20日双确认
- **价格位置**: 20/60/120日分位数

### 🔍 因子权重网格搜索

**原理**: 对 6 个因子类别（DMI/动量/均线/RSI/成交量/价格位置）的权重进行组合搜索，自动找到最优配置。

**搜索空间**:
- DMI: 2.0, 2.5
- 动量: 1.0, 1.5
- 均线: 1.0, 1.5
- RSI: 1.0
- 成交量: 1.0
- 价格位置: 1.0

**Top 5 最优组合**:
```

  1    1.89   34.12%   -9.66%    2.0    1.0    1.5   1.0   1.0
  2    1.82   30.79%   -9.69%    2.5    1.5    1.0   1.0   1.0
  3    1.75   30.10%   -9.69%    2.5    1.5    1.5   1.0   1.0
  4    1.72   30.05%   -9.49%    2.0    1.5    1.5   1.0   1.0
  5    1.64   28.19%  -13.66%    2.5    1.0    1.5   1.0   1.0
```

**结论**: 
- 最优权重组合: **DMI=2.0, 均线=1.5**（DMI 和均线权重最高）
- 动量因子权重在 1.0~1.5 之间表现均衡
- RSI/成交量/价格位置权重 1.0 即可

## 📋 策略逻辑

### V9 信号评分系统

```python
score = 0

# 1. DMI 信号 (核心，权重最高)
if +DI > -DI: score += 2
if ADX > 25: score += 1
if ADX 上升: score += 1

# 2. 多时间框架动量
if momentum_20 > 0: score += 1
if momentum_60 > 0: score += 1
if 多框架一致: score += 2

# 3. 均线系统
if 价格 > MA5: score += 1
if 价格 > MA20: score += 1
if 价格 > MA60: score += 1
if 多头排列: score += 2

# 4. RSI
if RSI < 30 (超卖): score += 1
if RSI < 70 (未超买): score += 1

# 5. 成交量
if 放量: score += 1
if 持续放量: score += 1

# 6. 财务因子 (同花顺)
if ROE > 15%: score += 1
if PE 合理: score += 1
if 营收增长: score += 1

# 买入条件: score >= 3
```

### 资金分配（风险平价）

```python
# 波动率倒数加权
volatility = 20日收益率标准差
weight_i = (1/vol_i) / Σ(1/vol_j)
position_size = capital * weight_i
```

## 🔍 诚实回测报告（2026-08-11）

**重要声明**: honest-round3 分支指出 V10/V11 存在严重问题，已通过诚实框架验证。

### V10/V11 被证伪的 4 大错误

1. **零卖出 = 买入持有**：V10 买入 47 次、卖出 0 次，本质是买入持有到底，不是交易策略
2. **市场状态切换从未触发**：310 天回测中没有任何一天触发状态切换逻辑
3. **样本内同段优化同段报告**：在 2024-2025 数据上优化参数，又在同一段数据上报告收益 → 自证其果
4. **仅 49 只股票非全量**：应为 HS300 全量（300 只），实际仅 49 只

### 诚实回测方法

- **数据范围**: 2022-01-04 ~ 2026-08-11（1624 个交易日）
- **拟合窗口**: 2022-2023（参数优化）
- **纯净 Holdout**: 2024-2026（从未参与优化）
- **Walk-Forward**: 5 折交叉验证，每段严格样本外

### 因子 IC 分析（样本内）

最大 |IC| = 0.1162（momentum_120），但所有因子 IC 均 < 0.15 → **无稳健信号**

### 诚实回测结果对比

| 配置 | Holdout 夏普 | WF-OOS 均夏普 | 结论 |
|------|-------------|---------------|------|
| 基准 (低频) | +0.27 | +0.02 | 无稳健 alpha |
| +vol_parity | +0.11 | +0.04 | 无稳健 alpha |
| +regime_risk | +0.27 | +0.02 | 无稳健 alpha |
| 基准 (高频) | **+0.30** | **+0.04** | 最优但仍 < 0.3 |
| +vol_parity (高频) | +0.20 | +0.09 | 无稳健 alpha |

### 诚实结论

**所有配置的 WF-OOS 均夏普 < 0.3 → 无稳健 alpha**

唯一有效的是**市场状态择时（regime_risk）**和**风险平价（vol_parity）**，但它们的独立贡献在 OOS 中几乎为零。

**下一步**: 放弃因子选股，专注市场状态择时 + 风险平价管理。
