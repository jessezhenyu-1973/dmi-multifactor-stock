# DMI 多因子量化选股策略系统

> 基于 DMI（Directional Movement Index）指标的多因子量化交易策略，集成同花顺/通达信/akshare 多数据源

## 项目概述

本项目是一个基于 DMI（Directional Movement Index）的多因子量化选股策略系统，支持多数据源融合回测。当前核心策略为**V10 智能优化策略**（因子权重网格搜索 + 市场状态切换），以及独立的**龙头战法选股系统**（右侧交易）。

> ⚠️ **重要诚实声明**: 经过严格样本外验证（Walk-Forward + Holdout），纯技术/量化选股策略未能产生稳健的 OOS alpha。所有主动选股策略在样本外验证中失败。建议参考龙头战法选股系统作为替代方向。

### 龙头战法选股系统 v1.0（当前活跃策略）

不做反弹，只做右侧交易。以板块轮动和资金流向为依据，选出最强龙头股。

```
第1层：市场状态识别 → 第2层：板块轮动分析 → 第3层：龙头股筛选（右侧交易）
  牛/熊/震荡          涨停池+资金流向        P>MA20>MA60
```

**右侧入场条件（必须全部满足）**：
- 价格 > MA20 > MA60（多头排列）
- 板块为当前最强主线（板块轮动确认）
- 非 ST、非涨停（基础过滤）

**止损纪律**：
- 跌破 MA20 → 减仓 50%
- 跌破 MA60 → 清仓
- 单票亏损 > 8% → 强制止损

### 诚实回测结论（2026-08-11）

| 版本 | 声称 | 诚实结果 | 原因 |
|------|------|---------|------|
| V10 | +34.12% | 买入持有幻觉 | 零卖出 |
| V12 | 多因子共振 | WF-OOS=0.00 | 因子 IC 衰减 |
| V13 | WF-OOS=0.84 | Holdout=-0.09 | 过拟合 |
| V14 | 简单趋势 | 亏损 30-46% | 趋势策略失效 |

**最终结论**: 在 2022-2026 A 股市场环境下，**纯技术/量化选股无法产生稳健 OOS alpha**。龙头战法选股系统为当前主要研究方向。
